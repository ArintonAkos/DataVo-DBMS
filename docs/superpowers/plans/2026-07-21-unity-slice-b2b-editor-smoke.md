# Unity Slice B2b: Editor Smoke Import Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Use the installed Unity `6000.5.4f1` Editor to source-control a real smoke-project lockfile and prove that the generated portable Core fixture and Mathematics adapters import, compile, and pass EditMode conversion tests.

**Architecture:** A tracked minimal Unity project retains Editor-generated `ProjectSettings`, `manifest.json`, `packages-lock.json`, source test code, and `.meta` files. A runtime-only local symlink points the smoke manifest's candidate dependency at a newly generated test fixture outside version control. The batch runner first creates that exact candidate, then invokes the pinned Unity Editor and rejects package-lock drift or failed test XML.

**Tech Stack:** Unity `6000.5.4f1` macOS ARM64 Editor (revision `d550df8bd089`), Unity Test Framework `1.7.0` bundled by that Editor, Unity Mathematics `1.4.0` bundled by that Editor, Bash, Node.js, NUnit, existing Core-candidate generator.

## Global Constraints

- This is B2b only: a clean Editor import and Mathematics/EngineTypes adapter proof. Do not add `com.datavo.unity.jobs`, Collections/Burst code, NativeArray/NativeSlice APIs, player builds, benchmarks, NuGet packaging, or a Unity support claim.
- `6000.5.4f1` is the authoritative Editor version. `ProjectVersion.txt`, runner assertions, logs, and committed package lock must name that exact version and revision.
- `DataVo.Core` remains Unity-free. Unity consumes only `scripts/prepare-unity-candidate.sh` output; never a workspace DLL or project reference.
- `com.datavo.core.candidate` is generated under a local `.generated` symlink and is never committed. The tracked project manifest names it only as `file:../.generated`.
- The lockfile is generated by the installed Editor. Do not hand-author a lock entry or choose Collections/Burst versions in this slice.
- Track smoke-project `ProjectSettings`, `Packages/manifest.json`, `Packages/packages-lock.json`, source assets, and their Unity-generated `.meta` files. Ignore `Library`, `Temp`, `Logs`, `UserSettings`, test output, and the generated candidate symlink.
- Static and Editor/Mono evidence do not prove Jobs, Burst, IL2CPP, Windows support, production save-data suitability, or public Unity support.

```csharp
[Test]
public void MathematicsFloat3_RoundTrips_XYZ()
{

    Assert.That(source.ToDataVoCell().AsFloat3(), Is.EqualTo(source));
}

[Test]
public void EngineVector3_RoundTrips_XYZ()
{
    var source = new Vector3(-4f, 5.25f, 6f);
    Assert.That(source.ToDataVoCell().AsVector3(), Is.EqualTo(source));
}

[Test]
public void Quaternion_Retains_All_Four_Components_Without_Normalization()
{
    var source = new quaternion(2f, -3f, 4f, -5f);
    Assert.That(source.ToDataVoCell().AsQuaternion().value, Is.EqualTo(source.value));
}

[Test]
public void Wrong_Vector_Length_Reports_Expected_And_Actual_Dimensions()
{
    var exception = Assert.Throws<ArgumentException>(() => CellValue.From(new[] { 1f, 2f }).AsFloat3());
    Assert.That(exception.Message, Does.Contain("Expected VECTOR(3) but received VECTOR(2)."));
}
```
